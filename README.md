## 中文版本

### 📋 项目简介

这是一个基于React + TypeScript + Vite构建的智能咨询Web应用，专注于美学设计咨询和个性化建议服务。该应用集成了Google Gemini AI，为用户提供专业的美学指导和咨询服务。

### ✨ 主要功能

- **智能咨询系统**: 基于AI的个性化美学咨询
- **照片指导**: 专业的拍照建议和技巧
- **问题选择**: 多维度的美学问题分析
- **报告生成**: 详细的咨询报告和建议
- **知识库**: 丰富的美学知识和案例
- **聊天功能**: 实时AI对话咨询
- **美学设计流程**: 完整的设计指导流程

### 🛠 技术栈

- **前端框架**: React 19.1.1
- **开发语言**: TypeScript
- **构建工具**: Vite 6.2.0
- **AI服务**: Google Gemini API
- **样式**: CSS Modules + 自定义样式
- **状态管理**: React Context

### 📦 安装和部署

#### 环境要求

- Node.js (推荐版本 >= 18.0.0)
- npm 或 yarn 包管理器
- Google Gemini API密钥

#### 本地开发

1. **克隆项目**
   ```bash
   git clone https://github.com/sooogooo/webapp-consultant-dudengyi.git
   cd webapp-consultant-dudengyi
   ```

2. **安装依赖**
   ```bash
   npm install
   # 或使用 yarn
   yarn install
   ```

3. **环境配置**
   - 复制 `.env.local` 文件（如果不存在请创建）
   - 设置你的 Gemini API 密钥：
   ```bash
   echo "GEMINI_API_KEY=your_gemini_api_key_here" > .env.local
   ```

4. **启动开发服务器**
   ```bash
   npm run dev
   # 或使用 yarn
   yarn dev
   ```

5. **访问应用**
   - 打开浏览器访问 `http://localhost:5173`

#### 生产环境部署

1. **构建项目**
   ```bash
   npm run build
   # 或使用 yarn
   yarn build
   ```

2. **预览构建结果**
   ```bash
   npm run preview
   # 或使用 yarn
   yarn preview
   ```

3. **部署到服务器**
   - 将 `dist` 目录中的文件上传到你的Web服务器
   - 确保服务器支持单页应用的路由重定向

#### 常见部署平台

**Vercel 部署**
```bash
# 安装 Vercel CLI
npm i -g vercel

# 部署
vercel --prod
```

**Netlify 部署**
- 连接GitHub仓库
- 构建命令: `npm run build`
- 发布目录: `dist`

**Docker 部署**
```dockerfile
# Dockerfile 示例
FROM node:18-alpine as builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
